## Turn on GitHub Pages

1. Go to your repo → **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` and folder `/ (root)` → **Save**.
4. Wait 1–2 minutes, then your site is live at:
   `https://dabtuquiskitfall2026.github.io/Dbatu_quiskitfall_fest_2026/`

## Things to edit before sharing the link

- **Registration link** — in `index.html`, find `<a href="#" class="btn btn-pink btn-lg">Open registration form</a>` and replace `#` with your real form URL.
- **Countdown** — in `main.js`, the `EVENT_START` constant sets the countdown target (currently 30 Oct 2026, 10:00 AM IST).
- **Schedule / Prizes / Footer links** — edit directly in `index.html`.
